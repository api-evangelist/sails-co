# Sails Co / Sails.js

> Sails Co. is a full-service web, mobile, and cloud studio (Y Combinator W15, Austin, TX) founded by the creators of Sails.js. Sails.js is an open-source, API-driven MVC framework for Node.js — built on Express and Socket.io — for building production-ready, realtime web apps and data-driven REST APIs, with the Waterline ORM and auto-generated "blueprint" REST APIs. This profile is generated by the API Evangelist enrichment pipeline; Sails Co is a framework/tooling company, not a hosted API provider.
